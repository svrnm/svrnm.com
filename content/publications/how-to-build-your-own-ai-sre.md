This hands-on lab builds an incident investigation agent in seven steps, from a model behind an endpoint to an agent that queries telemetry, reads application code and commit history, and files its findings as a GitHub issue. Along the way, the walkthrough shows how tools, instructions, and model choice affect an agent's investigation, including where it can still go wrong. The code is available in the [ai-sre-lab repository](https://github.com/bronto-community/ai-sre-lab).
